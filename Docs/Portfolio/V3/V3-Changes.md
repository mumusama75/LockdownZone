# V3 修改说明

V2 和原简历保持不变；本版聚焦关卡设计，保留声音和电梯两组玩法规则。未修改 UE 玩法代码、关卡或资产。

## 主要改动

- 首页明确岗位方向、两关原型阶段、本人职责和实际证据入口。AI 说明限定为代码辅助，保留第三方署名。
- 第一关空间页连接 B 门观察点；新增大幅玩家视角图，只标注真正可见的感染者、尸体及读卡器。投瓶落点与门内方向在平面图 / 文字中说明。
- 茶水间采用入口与深处奖励实机，奖励图裁切放大，不改亮度。明确当前“拥有且开启手电”是硬性拾取条件。
- 以全层风道收束为 10→06 的真实方案变更替换车库提亮主案例。图为关系示意，分析覆盖范围、风险差异、地面探索与自由度的取舍，没有编造玩家试验。
- 声音页按触发起点组织事件与计时，区分固定配置、位移 / 操作变量及并行关系。特别说明 7 秒不含取卡过程、14 秒不是投瓶后倒计时。
- 电梯体验页解释保护演出的代价；规则页解释输入、保留进度、重复触发和异常恢复，避免两页重复。
- 第二关仅保留一页，强调提前挪车和非强制击杀；继续标注灰盒状态。
- 去掉代理式核验口吻，分离交付记录与求职正文。通用限制集中于末页。

## 证据与验证

- 阅读 V2 全文、Python / SVG / HTML 源文件、已有截图、项目文档及声音 / 门禁 / 电梯相关实现。
- B 门当前配置与 DefaultGame.ini 一致：3 只、0.65 秒反应、12 秒强声承诺、8 秒搜索、14 秒电台周期、7 秒门全开保持、清空至少 1.2 秒。
- 补录尝试运行现有 StealthQA，75 项检查通过；这是受控引擎检查，不是开发者手动完成一次通关，更不是玩家统计。
- 10 页逐页渲染；调整压住物体的编号、风道图连接线与文字位置，并检查字体嵌入、文字提取及链接。
- Fab 作品页与 CC BY 4.0 许可页可访问；邮箱为实际 mailto 地址，未发送邮件。
