# 《封锁区：零号大厦》核心关卡设计简报 (Level Design Brief)

**设计目标**：构建单人搜打撤 FPS 垂直切片，围绕“观察威胁—获取工具—有限弹药交战—断电空间逆转—目标搜索与撤离”建立具备策略深度与空间可读性的心流体验。

---

## 命题一：开场教学——安全观察威胁，理解工具与资源限制

### 1. 现有设计问题
- **视线割裂与盲区**：玩家初始朝向正东 `(-3300, 0, 110)` 直面大玻璃窗，消防斧桌置于玩家身后南侧 `(-3300, -400)`，开场完全在视野盲区；手枪/手电桌位于左偏北 `(-3100, 490)`，缺乏视觉聚焦度。
- **资源感知滞后**：手枪拾取规格为 3/0（弹匣 3 发、备用 0 发），但玩家开枪前往往未注意到自身处于极度缺弹状态，容易在击碎玻璃后立即盲目对窗外两只感染者连续扣动扳机导致空仓遇险。

### 2. 拟改内容
- **机位与构图微调**：出生点朝向从纯东 (Yaw 0°) 微调为偏东北 (Yaw 15°)，使开场视野黄金分割线上自然容纳“左前方桌面（格洛克17、手电筒、工作台灯光圈）”与“正前方观察窗及窗外感染者影子”。
- **台灯与光带汇聚**：在手枪/手电桌上方增设一盏色温 4200K 的聚焦台灯，形成局部高反差光斑；在消防斧挂架处增加醒目的红白应急警示框与反射反光。
- **信息层级强化**：在拾取手枪瞬间，HUD 弹药数字（3/0）以亮黄闪烁提醒，状态提示明确写明：“手枪仅余 3 发底火，切勿挥霍；寻找场景弹药或切换近战”。

### 3. 预期玩家行为
- 玩家醒来后首先被前方晃动的感染者轮廓吸引（建立生存危机），随后视线自然滑向左侧台灯光圈内的格洛克17与手电筒。
- 拾枪后玩家看到 3/0 弹药，意识到无法肆意开火；在面对窗外两名感染者时，选择瞄准爆头或破窗后利用消防斧近战清理，并在安全门外走廊主动寻找第一箱 9mm 补给。

### 4. 验证方式
- 检查 `Docs/Overnight/Baseline/Screenshots/SliceQA_01_Opening.png` 与修改后 `Docs/Overnight/Phase2_Opening.png` 的机位构图对比。
- QA 自动化验证：未武装前敌人静止保护、三种武器拾取、手枪开火后坐力、换弹逻辑与弹药消耗全部 PASS。

## 命题二：中段取舍——偏离主线搜索的动机与代价

### 1. 现有设计问题
- **视线预告缺失**：北侧休息区与南侧机房深处的稀有高价值战利品（服务器备件，价值 $500，占 2×2 空间）平铺于地面，在主走廊无法预先观察。玩家没有“看见诱惑”的前提，无法形成真正的心理博弈。
- **空间竞争感知不足**：背包初版仅依靠简单容量计数，缺乏高阶拼图博弈与旋转机制；升级为 6×6（36格）空间网格背包后，武器（消防斧 2x6、手枪 2x2）、战术装具（手电 2x1）与大件战利品（备件 2x2）产生强烈的空间排他竞争。

### 2. 拟改内容
- **框架视线（Framed Sightline）**：
  - 在北侧隔断开口处布置翻倒的办公柜与泛光照明，使玩家在主走廊行进时能透过隔断缝隙直接瞥见发光的“服务器备件（粉红呼吸光圈）”和医疗包。
  - 在南侧机房主线保险丝台后方，通过机柜间隙架设微弱探照灯，直射深处备件箱，形成明确的视线纵深。
- **6×6 空间网格背包与旋转交互**：
  - 采用 6×6（36格）空间网格，武器/装具物理进包，支持按 R 键旋转（如 2×1 ↔ 1×2，2×6 ↔ 6×2）。当空间不足以容纳 2×2 备件时，HUD 明确反馈所需尺寸，场景道具原子保留绝对不销毁。

### 3. 预期玩家行为
- 玩家经过主走廊时被框架视线吸引，看到高额价值道具，开始权衡：“多走 25 米并花费背包 2×2 矩形空间，还是保留空间放备用弹药和医疗包保证安全撤离？”
- 追求高撤离价值的玩家会主动打开背包，通过 R 键旋转或丢弃低价值零件，腾出空间装入 $500 备件；保守玩家则选择携带双医疗包和充足弹药稳健推进。

### 4. 验证方式
- 自动化 QA 路线验证：测试“直接撤离路径”与“满载高价值战利品撤离路径”，比对最终结算金币（直接撤离 $0 vs 探索撤离 $1120）。
- 截图验证：走廊框架透视视线对比图、背包满载双格备件成功与失败提示截图。

## 命题三：断电逆转——利用先前空间记忆寻找目标并返回撤离

### 1. 现有设计问题
- **断电后辨识度塌陷**：第 4 次击杀后触发全场断电，场景进入极低照度。南侧机房门洞与北侧配电间门洞在暗光下形体轮廓高度同质化（均为 3.5m 高平板门洞），玩家难以依靠建筑形体在暗中辨识方向。
- **手电桌面热点眩光**：手电开启时，近距桌面反射严重过曝白化，不仅遮挡视线，更破坏了暗黑生存的氛围与纵深阅读。

### 2. 拟改内容
- **剪影地标与中途确认物（Silhouetted Landmarks）**：
  - **机房入口（南侧）**：门洞上方增加带有黄色警示斜纹与散热百叶窗格栅的机柜剪影，地面增加反光地贴；在黑暗中只要手电扫过即可凭独特几何外形辨认。
  - **配电间入口（北侧）**：门楣加装频闪频率约 1.2s 的微弱红色应急指示灯柱（Beacon）与高压警示标，成为北侧走廊尽头的视觉灯塔。
  - **十字枢纽路标**：在中央办公区通往南北两侧的立柱上增加物理导向路牌（ASCII/反光符号：`[SERVER ->]` 与 `[POWER ->]`）。
- **手电与应急灯平衡优化**：
  - 调整手电近景衰减与环境光反弹，降低第一人称武器近距镜面高光，保留手电光锥外的暗区层次。
  - 保留并强化应急地灯，勾勒出核心通道走道边缘，使断电既带来压迫感，又不阻断通畅移动。

### 3. 预期玩家行为
- 断电瞬间警报声与灯光骤降让玩家进入警惕状态，本能按下 F 开启手电。
- 玩家环顾四周，依托前期探索建立的空间认知和走廊立柱路标，迅速判断南侧机房方位；在机房拿到保险丝后，望向北侧可见微弱频闪的配电红光，形成清晰的返程引导，最后通电时看到远端大开的绿色撤离气闸门，顺理成章奔向撤离点。

### 4. 验证方式
- 实机截图对比：机房入口与配电间入口在“正常照明 / 断电黑暗 / 开启手电 / 恢复供电”四种状态下的全景机位截图。
- 主线流程回归测试：QA 机器人顺利完成断电触发、机房取保险丝、配电间通电、气闸撤离的全链条交互。
