# 《封锁区：零号大厦》关卡空间度量衡与建筑规范白皮书 (Spatial Metrics & Level Design Bible)

> **设计定位**：单人第一人称战术搜打撤 FPS 关卡度量衡与空间拓扑标准  
> **适用引擎**：Unreal Engine 5.8 (基于真实厘米坐标制构建，1 UU = 1 cm)  
> **关卡尺度**：7600 cm × 4200 cm × 350 cm (76m × 42m × 3.5m，总建筑面积 3192 ㎡)  
> **文档用途**：向主策划（Lead Designer）、主关卡（Lead Level Designer）与关卡美术（Level Artist）交付严密可执行的几何尺度、掩体标准、交火距离与空间层级规范。

## 一、角色空间包络与运动度量衡 (Character Kinematic & Collision Envelope)

在关卡设计的初级阶段，空间尺度的失控往往源于对玩家角色碰撞体（Capsule Envelope）和运动参数的忽视。《封锁区：零号大厦》严格基于下列第一人称角色物理包络进行白模（Blockout）放样：

| 度量衡项目 | 引擎数值 (UU / cm) | 现实世界对应参考 | 关卡设计约束与设计意图 |
| :--- | :--- | :--- | :--- |
| **胶囊体站立高度 (Standing Height)** | **180 cm** | 成年人站立身高 | 所有门洞净空、悬挂标牌、横梁底缘必须大于 220 cm，杜绝卡头穿模。 |
| **胶囊体站立半高 (Half-Height)** | **90 cm** | 质心基准高度 | 物理拾取射线与碰撞解算的基准参考点。 |
| **胶囊体蹲姿半高 (Crouch Half-Height)** | **48 cm** (总高 96 cm) | 战术屈膝蹲姿 | **Ctrl 潜行蹲下核心度量**；使角色头部完全潜入 78cm 办公桌与 45cm 茶几遮蔽线以下。 |
| **胶囊体半径 (Radius)** | **42 cm** (直径 84 cm) | 人体肩宽 + 装备厚度 | 最小通行狭道不得小于 110 cm（双侧预留 ≥13 cm 冗余防擦墙卡顿）。 |
| **第一人称视点高 (Eye Height)** | **165 cm** (站立) / **105 cm** (蹲姿) | 成年人平视 / 蹲姿平视 | **关卡黄金视线（Sightline）基准面**；站立平视桌面物资，蹲下进入掩体后射击盲区。 |
| **最大跨越台阶 (Max Step Up)** | **45 cm** | 建筑标准台阶高度 (15cm×3) | 允许角色直接跨过地面薄电缆、小型破裂瓦砾；≥50 cm 物体强制充当物理阻挡。 |
| **常规走动速度 (Walk Speed)** | **375 cm/s** (3.75 m/s) | 慢跑巡逻速度 | 用于推算暗夜搜寻与巡回折返的基准心理时长。 |
| **战术冲刺速度 (Sprint Speed)** | **600 cm/s** (6.0 m/s) | 全力突击与撤离奔跑 | 气闸开启后的最终极限逃脱跑速；76 米对角线全速折返需约 12.6 秒。 |
| **潜行静默速度 (Crouch Sneak Speed)** | **180 cm/s** (1.8 m/s) | 压步战术慢走 | **Ctrl 潜行静默机动**；大幅降低脚步噪音，敌方视觉侦测半径削减 55%。 |
| **武器第一人称偏移 (Viewmodel)** | `X: 62, Y: 20, Z: -27` | 携行抵肩基准姿态 | 贴墙判定距离；当角色距障碍物小于 65 cm 时，武器枪管收紧防穿墙。 |

### 1. 战术潜行与掩体遮蔽系统 (Tactical Sneak & Cover Occlusion)

- **操作双模态**：支持 `LeftControl`（长按潜行）与 `C`（一键切换姿态），胶囊体在 48cm 与 90cm 之间平滑解算。
- **动态仇恨削减**：敌人基础索敌半径（如 1200 cm）针对蹲姿玩家即时削减 **55%**（有效侦测距离降至 540 cm）。
- **视线低掩体射线阻断 (Raycast Cover Check)**：
  当玩家处于蹲姿时，视平线降至 105 cm，与敌人之间的探测射线若被 78 cm 办公隔断或 45 cm 咖啡桌拦截，立即触发**掩体完全隐匿**，强制中断 AI 追逐索敌。
- **战术 HUD 静默反馈**：实时显示 `[ ▼ 潜行静默中 · 敌方侦测-55% · 掩体遮蔽 ]`，直观传递掩体安全性。

掩体高度设计决定了 FPS 战斗的深度。《封锁区：零号大厦》坚决摒弃“随机摆放模型作为掩体”的业余做法，全场掩体严格划分为**低掩体**与**高掩体**两级离散规格：

```

      角色蹲姿视平线 (110cm) ──── ┐      │
                                 │ 掩体防守  │
 [ 低掩体 Low Cover: 45~78cm ] ──┴───────┴─── (咖啡桌 45cm / 办公桌 78cm / 接待吧台 110cm)
 
 [ 高掩体 High Cover: 180~350cm ] ─────────── (承重立柱 200cm / 服务器机柜 220cm / 混凝土墙 350cm)
```

## 四、交火区间与视线阻断设计 (Engagement Envelopes & Sightline Cut-offs)

室内恐怖搜打撤的核心在于**控制视线距离（Sightline Length）**。若视线过远，玩家可在安全距离点杀怪物，失去紧张感；若视线过近，玩家将遭遇无预警冲脸，产生无力挫败感。

### 1. 三层交火距离区间定义

```
交火距离区间 (Engagement Distance)

  0m        2.5m                   8m                                 16m             22m+ (截断)
  ├── 接触区 ──┼────── 近距交火 ──────┼────────── 中距拉扯 ───────────┼──── 视线阻断 ───┤
    CQB Melee     Hallway Spray          Desk Crossfire / ADS Tap        Cut-off Wall
```

1. **接触近战区 (Zone 0: 0 ~ 2.5 米)**：
   - 消防斧攻击有效半径（180 cm），感染者扑咬判定半径（160 cm）。
   - 视觉特征：感染者满屏面部细节、血液飞溅贴图，压迫感最高。
2. **走廊近距交火区 (Zone 1: 2.5 ~ 8 米)**：
   - 格洛克 17 腰射（Hip-fire）首选距离。在此距离内后坐力上抬不影响躯干命中率。
   - 典型场景：观察窗破裂后过道掩体拉扯、主管办公室拐角狭路相逢。
3. **中距工位拉扯区 (Zone 2: 8 ~ 16 米)**：
   - 必须通过右键瞄准（ADS）降低后坐散射；需要 2~3 发点射爆头。
   - 典型场景：从中央十字路口向北侧休憩区、南机房入口对射。
4. **最大视线截断硬指标 (Max Sightline Cut-off: ≤ 22 米)**：
   - **硬性设计规则**：整个 76m×42m 楼层中，**绝对不允许出现贯穿超过 22 米的直视长廊**。
   - **实现手法**：在主干道每隔 15~18 米布置一道 45° 偏角隔断、承重柱或悬挂门楣，将直视光路切断；这既杜绝了玩家跨半张地图开枪破坏怪物 AI 节奏，又保证了视锥遮挡剔除（Occlusion Culling）下的极低渲染负担。

### 2. 交互操作与拼图规则

- **自由空间放置**：玩家可自由拖拽、移动物资至任意连续合法空闲格子，支持鼠标拖拽与键盘方向键导航。
- **动态 R 键旋转 (Rotate)**：仅在玩家**拿起物品悬空**时按 `R` 键触发 $90^\circ$ 旋转（如 2×1 ↔ 1×2，2×6 ↔ 6×2）；若背包关闭或手中无物，`R` 键严格保持为武器换弹，绝不误触。
- **原子拒收机制 (Atomic Rejection)**：当拾取 2×2 备件或 2×6 斧子但包内无连续矩形空位时，系统弹出明确拒收原因（如 `背包已满：需连续 2x2 空位`），场景物品**绝不销毁**，保障资源绝对安全。
- **右键取消放回 / Delete 丢弃**：手中拿起物品时，右键立即安全放回原位；选中物品按 `Delete` 丢弃并物理清空所占网格。

## 七、关卡设计自查核对清单 (Level Designer Checklist)

任何对本关卡几何或玩法的后续改动，必须逐项通过下列**关卡自查核对清单**：

- [x] **通行性**：所有玩家可达走道净宽 ≥140 cm，主干道 ≥360 cm，门洞通行净高 ≥220 cm。
- [x] **潜行与掩体有效性**：Ctrl 蹲下胶囊半高 48 cm，敌方探测削减 55%；低掩体（45~78 cm）完全阻断站立/蹲姿视线。
- [x] **视线截断**：全图无超过 22 米的直视射线，避免狙击无脑清怪。
- [x] **6×6 空间背包拼图**：36 格网格，武器/手电物理入包，支持 R 键旋转与原子拒收。
